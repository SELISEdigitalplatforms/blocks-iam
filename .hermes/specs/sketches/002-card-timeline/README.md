## Variant: Card Timeline

### Design stance
Visual, story-driven, editorial. Each event is a card on a vertical timeline with a connecting line. Emphasizes narrative and context over raw density.

### Key choices
- Layout: Vertical timeline with dot connectors, card stats at top, chip filters
- Typography: Slightly larger — 14px event titles, 28px stat counts
- Color: Dark theme with gradient stat cards, rich event card details with extras section
- Interaction: Cards expandable, filter chips toggle, load-more pagination

### Trade-offs
- Strong at: Visual appeal, narrative understanding, showing event context
- Weak at: Density (fewer events visible at once), scanning speed, requires scrolling
- Best for: Managers/stakeholders reviewing recent activity, audit contexts

### Best for
- Executives or non-technical users reviewing activity
- Audit/compliance review sessions
- Lower-volume tenants (< 200 events/day)
